套接字(socket)

在POSIX/Linux下，原型为

参数 含义 常见取值
domain / af 协议族 AF_INET、AF_INET6、AF_UNIX、AF_PACKET
type 套接字类型 SOCK_STREAM、SOCK_DGRAM、SOCK_RAW、SOCK_SEQPACKET
protocol 具体协议，通常为 0 0、IPPROTO_TCP、IPPROTO_UDP、IPPROTO_ICMP
  • protocol = 0 时，系统根据 domain + type 自动选择默认协议：
    • AF_INET + SOCK_STREAM → TCP
    • AF_INET + SOCK_DGRAM → UDP

socket(2, 2, 0);这里表示用的是IPV4协议并且是UDP 数据报模式

UDP 是一种无连接、不可靠、面向数据报的传输层协议，头部小、延迟低、开销小，适合实时通信和简单查询；可靠性需要应用层自己实现。

之前代码 sub_15E74 中有 v7 = a1 + 82;，这里的 v7 就是指向发送/响应缓冲区的报头起始地址。

  • *(_BYTE *)(v7 + 1) = v8[1]; 对应填充 Type。
  • *(_BYTE *)(v7 + 2) = 1; 对应填充 Code。
  • *(_BYTE *)(v7 + 3) = 0; 对应填充 ReplyInfo。
  • *(_DWORD *)(v7 + 4) = htonl(0); 对应初始化 PktLength。
  • v2 = ((unsigned __int8)v8[9] << 8) | (unsigned __int8)v8[8]; 正好对应图中 PktID（小端序读入，原样写入 v7 + 8 和 v7 + 9）。

图中 Digest 占了整整 16 字节（第 0x0C 到 0x1B 字节）。它的计算方式通常是：先将报头中 Digest 的位置全部清零，然后将整个数据包（报头+数据）进行 MD5 运算，最后将算出的 16 字节摘要填入。
接收方收到包后，会重新计算 MD5 并比对，以防数据被篡改。如果是加密的 TDDP（通常结合 DES），摘要和加密结合在一起保证通信安全。

会发现，就算这样做了也没有办法拿到一个交互式的shell。

这是因为/bin/sh 的 stdin 是管道，来自 tftp -gr 的输出。
